How It Works

What Should I Build? is a highly interactive, personalized, and robust developer's sandbox designed to cure developer's block. Built using a modern Java Servlet API and backed by a high-performance relational database, it customizes suggestions based on your exact choice of technology stack, project difficulty level, and planned completion timeline.

Key Features

  • Smart Fallback Algorithm: If an exact preference match isn't found in our curated DB, the algorithm intelligently eases timeline constraints to return relevant stack results rather than failing.
  • Controlled Shuffle: Users are granted up to three shuffles per generation request, keeping selections fresh and encouraging spontaneity.
  • Persistent Cloud Vault: Save your favorite suggestions instantly into your secure dashboard vault.
